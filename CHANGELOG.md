# Changelog

## 1.0.0 - Unreleased

First release, for WSO2 Identity Server 7.3.

- Access Evaluation and Access Evaluations APIs, and PDP metadata, per tenant.
- User, agent and application subjects.
- Decisions with the identity server's token rules: role audiences, roles through groups, `RBAC` and `No Policy`.
  Locked and disabled accounts and disabled applications are denied.
- The `internal_authzen_evaluate` scope, audit logging and `X-Request-ID` echo.
